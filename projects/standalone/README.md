# standalone

## Visão geral

Tarefas que não pertencem a nenhum projeto: um ajuste pontual, uma investigação curta ou uma pendência que não justifica uma pasta própria. Quando um assunto passa a ter várias tarefas relacionadas, ele vira projeto (`ws project new <slug>`) e as tarefas se mudam para lá.

Aqui só existe a pasta `tasks/`. Decisões, evidências e anexos de uma tarefa ficam no próprio arquivo dela; se isso crescer, é sinal de que ela merece um projeto.
